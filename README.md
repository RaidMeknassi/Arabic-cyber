# الأمن السيبراني في 10 دقائق

## 🌐 [افتح الموقع ← raidmeknassi.github.io/Arabic-cyber](https://raidmeknassi.github.io/Arabic-cyber/)

خريطة طريق عربية لتعلّم الأمن السيبراني من الصفر — درس واحد في 10 دقائق في كل مرة.

📲 **على الهاتف:** افتح الرابط وستظهر نافذة «ثبّت التطبيق على هاتفك» — أو اضغط زر «📲 تثبيت» في الأعلى.

## إضافة الدروس
كل شيء في ملف `data.js`:
- لتغيير الدروس أو إضافتها: عدّل قائمة `LEVELS`.
- لإضافة فيديو يوتيوب لدرس: أضف سطرًا في `VIDEOS`، مثل `"1.2": "AbCdEf12345"`.

## الصفحات
- `index.html` — الصفحة الرئيسية وخريطة طريق المبتدئ
- `level.html?l=b0` … `b6` — صفحة كل مستوى ودروسه

## النسخ الاحتياطية
- الفرع `backup-v1` — النسخة الأولى قبل إضافة التطبيق
